# LinkedIn post

I have built **FlowPilot**, an AI-assisted revenue operations dashboard for small and
medium-sized businesses.

Many growing teams receive leads from websites, campaigns, referrals, and external
tools, but the information often becomes scattered across spreadsheets, inboxes, and
CRM systems. This leads to slow responses, inconsistent qualification, and limited
pipeline visibility.

FlowPilot demonstrates how a single workflow can:

- capture inbound leads through a webhook designed for n8n;
- prioritize opportunities using transparent scoring logic;
- generate lead summaries and recommended next actions;
- show pipeline health, projected MRR, and response-time metrics;
- create an executive weekly digest;
- track automation activity and estimated time saved.

I built the MVP end to end, including the Node.js backend, API endpoints, analytics
logic, AI-assisted qualification, responsive dashboard, and black-and-gold interface.

The project currently uses demo data and a local AI fallback, with optional OpenAI
integration. My next steps are PostgreSQL persistence, authentication, a real CRM
integration, tests, and public deployment.

This project helped me combine full-stack development, data analysis, workflow
automation, and applied AI around a real business problem.
